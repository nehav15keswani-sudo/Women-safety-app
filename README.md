# 🛡️ Women Safety App

## 📖 Overview
Women Safety App is designed to provide quick emergency support and safety features for women.  
It uses **Java Swing** for the user interface and **MySQL** for backend data storage.
**Main point** it runs **offline** 

---

## ✨ Features
- 🚨 **Emergency Alert**: Send instant alerts to registered contacts.
- 📍 **Location Tracking**: Share live location with trusted people.
- 🔒 **Secure Login**: User authentication with database support.
- 📊 **User-Friendly Dashboard**: Simple and intuitive interface.

---

## 🛠️ Tech Stack
- **Frontend:** Java Swing  
- **Backend:** MySQL Database  
- **IDE:** NetBeans / IntelliJ IDEA  
- **Version Control:** Git & GitHub
